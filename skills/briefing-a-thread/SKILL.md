# Briefing a thread

A thread starts with nothing but its message and its repository. Give it:

- **Goal**: the outcome, in one or two sentences.
- **Decisions**: what the user already decided, so the thread does not
  reopen it.
- **Limits**: what it must not do (merge, release, touch other work).
- **Done**: what to hand back, and which evidence.

Leave out history the thread does not need. A long brief is a large
context; point to issues, pull requests or files instead of pasting them.
